# Sakshi — Portfolio

A second, distinct portfolio design with an editorial dark hero, project index, and lime-accented interactive playground. Built with plain HTML, CSS, and JavaScript.

Open `index.html` in a modern browser. The prompt builder and portfolio FAQ work locally. The live weather lookup requires internet and uses the public Open-Meteo API without a client-side key.

The student profile and project summaries are based on the source files supplied for the original portfolio. Update them with Sakshi’s verified personal information and real project links before publishing.
